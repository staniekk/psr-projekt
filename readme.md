Przedmiot: Programowanie systemów rozproszonych



Temat: Implementacja algorytmów synchronizacji zegarów. Implementacja w języku Python. Komunikacja między procesami przez UDP. Porównanie dokładności dwóch metod: - Algorytm Berkeley - Algorytm Cristiana + krótka analiza i dokumentacja
